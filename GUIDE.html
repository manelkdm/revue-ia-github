Revue GitHub avec sept agents

Les sept agents analysent les exigences, le code, la qualité, la conformité, les tests et la sécurité, puis produisent une synthèse. Le rapport final regroupe les constats répétés et conserve leurs preuves.

Essai local sous Windows

python -m venv .venv
./.venv/Scripts/python.exe -m pip install -e .
./.venv/Scripts/python.exe -m review.cli demo

Deux fichiers sont créés dans runs/IDENTIFIANT/ : review.json et report.md. Aucun service n'est contacté pour cette démonstration.

Revue réelle

Copier .env.example vers .env, renseigner le jeton GitHub et démarrer Ollama avec qwen2.5-coder:7b.

Dans la description de la PR, ajouter facultativement Issue liée : #42. Sans issue, la revue continue en signalant l'absence d'exigences.

./.venv/Scripts/python.exe -m review.cli review --repo PROPRIETAIRE/DEPOT --pr 1

Les rapports sont consultatifs. La publication est manuelle pour le moment.

Consulter le guide détaillé, les workflows et les vérifications réalisées.
